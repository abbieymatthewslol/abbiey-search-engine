Pricing

Search is free for typical use, with a soft limit for anonymous and signed-in free accounts. Heavy users can unlock higher limits when checkout is enabled. There are no ad slots in the result list.

Developers can use the public JSON API with a monthly free allowance; usage beyond that is metered via Stripe as described in the API docs.
