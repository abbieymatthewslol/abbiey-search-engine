# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If a scheduled or webhook-driven automation run does not have a clear task yet, use the repository templates below instead of freeform placeholders:

- `AUTOMATION_TASK_TEMPLATE.md` (quick task brief)
- `.github/agents/TASK_DEFINITION_TEMPLATE.md` (full checklist + acceptance criteria)

For vague prompts such as "idk what to put here", copy one of these templates and fill it with the target subsystem, expected behavior, and verification steps.
