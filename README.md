# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If a scheduled or webhook automation run needs a task prompt, start from
[`AUTOMATION_TASK_TEMPLATE.md`](./AUTOMATION_TASK_TEMPLATE.md).
It provides:

- required context to include
- clear acceptance criteria
- safe defaults when the goal is unclear
