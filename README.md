# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If you are configuring a cron/webhook agent run and are not sure what prompt to provide:

- Start with `AUTOMATION_TASK_TEMPLATE.md`
- Use `.github/agents/TASK_DEFINITION_TEMPLATE.md` for detailed acceptance criteria

These templates reduce ambiguous runs and keep automation changes small, testable, and safe.
