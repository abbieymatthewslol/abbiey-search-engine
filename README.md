# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If you run scheduled/background automation, provide a concrete objective instead of an empty placeholder prompt.

- Use [`AUTOMATION_TASK_TEMPLATE.md`](./AUTOMATION_TASK_TEMPLATE.md) as the default copy/paste format.
- Include explicit validation commands and expected outcomes in every automation task.
