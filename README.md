# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If a cron or automation run does not provide a clear task, use
`AUTOMATION_TASK_TEMPLATE.md` to define a concrete request before making
non-trivial changes.
