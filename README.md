# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

For scheduled/background runs, define a concrete task prompt using
[`AUTOMATION_TASK_TEMPLATE.md`](AUTOMATION_TASK_TEMPLATE.md). Avoid ambiguous prompts so automations can execute reliably without human clarification.
