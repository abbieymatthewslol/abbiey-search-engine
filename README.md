# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If an automated run is triggered without a clear task (for example, a prompt like "idk what to put here"), use the task template in [`AUTOMATION_TASK_TEMPLATE.md`](./AUTOMATION_TASK_TEMPLATE.md).

The template includes:
- a copy/paste structure for actionable prompts
- examples for bugfix, feature, refactor, and docs tasks
- a quality checklist so automation runs can execute end-to-end without clarification
