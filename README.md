# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

When creating Cursor/GitHub automation prompts, use:

- [`AUTOMATION_TASK_TEMPLATE.md`](AUTOMATION_TASK_TEMPLATE.md) for a quick copy/paste structure
- [`.github/agents/TASK_DEFINITION_TEMPLATE.md`](.github/agents/TASK_DEFINITION_TEMPLATE.md) for detailed agent-friendly examples

If an automation run starts with a vague prompt (for example, "idk what to put here"), prefer low-risk docs maintenance that restores these templates and keeps prompt guidance current.
