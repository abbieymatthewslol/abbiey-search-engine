# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation prompts

If you are setting up a cron/webhook automation and are not sure what to write, use `AUTOMATION_TASK_TEMPLATE.md` for a copy/paste task format with examples and a safe fallback prompt.
