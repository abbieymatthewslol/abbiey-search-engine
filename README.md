# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

When triggering Cursor automation, avoid placeholder prompts (for example, "idk what to put here").

- Use `AUTOMATION_TASK_TEMPLATE.md` for a copy/paste `user_query` format.
- If context is limited, start from the safe maintenance example in that template.
- Additional examples live in `.github/agents/TASK_DEFINITION_TEMPLATE.md`.
