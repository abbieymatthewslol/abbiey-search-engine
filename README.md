# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

For scheduled/background runs, avoid vague task prompts. Use
[`AUTOMATION_TASK_TEMPLATE.md`](./AUTOMATION_TASK_TEMPLATE.md) to provide:

- a clear objective,
- explicit in-scope/out-of-scope boundaries, and
- concrete validation commands.
