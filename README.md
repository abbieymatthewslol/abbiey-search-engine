# abbiey.search

Private, fast search with no query logging and no third-party trackers. Built with Python and Flask; see `CLAUDE.md` for the full stack, features, and how to run the app locally.

## Automation

If an automation trigger prompt is empty or vague, use `AUTOMATION_TASK_TEMPLATE.md` to define:

- a concrete objective,
- explicit scope and non-goals,
- acceptance criteria,
- validation commands, and
- expected deliverables.

Copy/paste the template and fill each section before running scheduled or webhook tasks.
